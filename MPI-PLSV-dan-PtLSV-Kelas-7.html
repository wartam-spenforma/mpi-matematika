DASAR PEMIKIRAN

Kenali dua bentuk linear

Keduanya hanya memuat satu variabel berpangkat satu. Bedanya terletak pada tanda hubungan dan bentuk jawabannya.

Persamaan Linear Satu Variabel

Kalimat terbuka dengan tanda sama dengan. Nilai variabel membuat ruas kiri dan kanan bernilai sama.

ax + b = c,  a ≠ 0

Pertidaksamaan Linear Satu Variabel

Kalimat terbuka dengan tanda <, >, ≤, atau ≥. Jawabannya biasanya berupa sekumpulan nilai.

ax + b < c,  a ≠ 0
Jaga kedua ruasLakukan operasi yang sama pada ruas kiri dan kanan.
Tujuan: variabel sendiriSingkirkan konstanta, lalu koefisiennya.
Ingat tanda berbalikJika PtLSV dikali atau dibagi bilangan negatif.
SIMULASI 1

Neraca kesetaraan

Persamaan ibarat neraca seimbang. Tambah atau kurangi kedua ruas dengan bilangan yang sama, lalu sederhanakan sampai nilai x terlihat.

Mulai dari 2x + 4 = 12

Setiap balok biru bernilai x dan setiap bulatan bernilai 1.

2x + 4 = 12Kedua ruas tetap seimbang saat x = 4

Tambah atau kurangi kedua ruas

Gunakan bilangan negatif untuk mengurangi. Contoh: −4 berarti kurangi 4 dari kedua ruas.

Bagi kedua ruas

Pembagian hanya dapat dilakukan jika semua suku habis dibagi.

Coba kurangi kedua ruas dengan 4.

PENERAPAN

Dari cerita menjadi model matematika

Cari hal yang belum diketahui, ubah hubungan dalam cerita menjadi kalimat matematika, lalu selesaikan dan periksa maknanya.

Contoh: biaya sewa sepeda

Biaya awal sewa sepeda Rp5.000 dan biaya tiap jam Rp8.000. Dita membayar Rp29.000. Berapa jam Dita menyewa?

1Misalkan lama sewa = x jam.
2Model: 8.000x + 5.000 = 29.000
38.000x = 24.000, sehingga x = 3.
4Jadi, Dita menyewa sepeda selama 3 jam.

Empat langkah andal

  1. Tentukan variabel dan satuannya.
  2. Temukan kata kunci: jumlah, selisih, paling banyak, minimal.
  3. Buat model PLSV atau PtLSV.
  4. Periksa jawaban terhadap konteks cerita.
“Paling banyak” → ≤   •   “sedikitnya” → ≥
